# qrcodegen

Nayuki's QR Code generator library, C++ edition, vendored unmodified from
https://github.com/nayuki/QR-Code-generator (`cpp/qrcodegen.hpp` and
`cpp/qrcodegen.cpp` at commit 3c6d0b3cefb4). MIT licence: see the header of
each file, and `license.txt` at the top of this repository.

Used to draw the QR code for the Raspberry Pi Connect device sign-in in
embedded mode, where there is no browser to sign in with.
