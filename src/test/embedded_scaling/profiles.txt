# Display profiles rendered by screenshots.sh.
#
# Columns:
#
#   name       output file name and report label
#   resolution the panel's native mode, used both for the fake connector and
#              for the offscreen screen the UI is rendered onto
#   edid       EDID recipe for the connector (see mkedid.sh), or "-" for a
#              panel that reports no EDID at all
#   dpi        logical DPI for the rendering screen, or "auto" to hold it at
#              Qt's base DPI. Keep "auto" unless you mean to deviate: the
#              offscreen plugin turns logicalDpi/logicalBaseDpi into a device
#              pixel ratio of its own, and on linuxfb that ratio comes from
#              QT_SCALE_FACTOR alone. Anything else scales the UI twice.
#   scale      the QT_SCALE_FACTOR this profile must run at; the run fails if
#              the scaling code picks anything else
#

# 43-inch-class rows now agree: the television's EDID can no longer change the
# UI. What varies across the list is resolution, and each row should render the
